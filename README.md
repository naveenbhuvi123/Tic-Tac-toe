# Tic-Tac-Toe Game

A modern, responsive implementation of the classic Tic-Tac-Toe game built with HTML, CSS, and vanilla JavaScript.

![Game Preview] https://tic-tac-toe-swart-one-ssxrkqzf2e.vercel.app/

## Features

- 🎮 Classic 3x3 Tic-Tac-Toe gameplay
- 🎨 Modern UI with hover effects and responsive design
- 🎯 Two-player turn-based gameplay
- 🌈 Different colors for O's and X's
- 🏆 Winner announcement with celebration emojis
- 🔄 Reset game and New Game options
- 📱 Responsive design - works on desktop and mobile devices
- 🎭 Beautiful gradient background
- ✨ Hover effects on game cells

## How to Play

1. Open `index.html` in your web browser
2. Players take turns clicking empty cells to place their mark (O or X)
3. O's are displayed in red, X's in blue
4. First player to get 3 in a row (horizontally, vertically, or diagonally) wins
5. If all cells are filled without a winner, the game is a draw
6. Click "Reset" to clear the current game
7. Click "New Game" after a win/draw to start fresh
